# PDF OCR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Users can drop or select a PDF file in the OCR view. Each PDF page is rendered to a canvas data URL via PDF.js and added to the existing multi-page pipeline. The rest of the OCR flow (multi-page concatenation → Tesseract → save) is unchanged.

**Architecture:** `src/lib/pdfToImages.ts` uses `pdfjs-dist` to render PDF pages to canvas and return an array of JPEG data URLs, one per page. `useImageLoader` is extended to accept PDF files: it calls `pdfToImages` and pushes the resulting data URLs as pages. `Dropzone` is updated to accept `application/pdf`. `pdfjs-dist` is loaded dynamically (via dynamic `import()`) so it does not bloat the initial bundle; its worker is pointed at the CDN copy so no webpack config changes are needed.

**Tech Stack:** `pdfjs-dist` (npm), Canvas 2D API, TypeScript, React

### Task 2: pdfToImages utility

**Files:**
- Create: `src/lib/pdfToImages.ts`

- [ ] **Step 1: Create the utility**

```typescript
// src/lib/pdfToImages.ts
// Dynamically loads pdfjs-dist to keep the initial bundle lean.
// Renders each PDF page to a JPEG data URL at 150 DPI.

const PDF_SCALE = 150 / 72  // 150 DPI (PDF default unit = 1/72 inch)

export async function pdfToImages(
  file: File,
  onProgress?: (done: number, total: number) => void,
): Promise<string[]> {
  // Dynamic import — pdfjs-dist is large (~1 MB); defer until first PDF is loaded
  const pdfjsLib = await import('pdfjs-dist')

  // Use the CDN worker so we don't need any webpack/next.config changes
  pdfjsLib.GlobalWorkerOptions.workerSrc =
    `https://cdn.jsdelivr.net/npm/pdfjs-dist@${pdfjsLib.version}/build/pdf.worker.min.mjs`

  const arrayBuffer = await file.arrayBuffer()
  const pdf = await pdfjsLib.getDocument({ data: arrayBuffer }).promise
  const total = pdf.numPages
  const dataUrls: string[] = []

  for (let pageNum = 1; pageNum <= total; pageNum++) {
    const page = await pdf.getPage(pageNum)
    const viewport = page.getViewport({ scale: PDF_SCALE })

    const canvas = document.createElement('canvas')
    canvas.width  = Math.round(viewport.width)
    canvas.height = Math.round(viewport.height)

    const ctx = canvas.getContext('2d')!
    await page.render({ canvasContext: ctx, viewport }).promise

    dataUrls.push(canvas.toDataURL('image/jpeg', 0.92))
    canvas.width = 0  // release memory

    onProgress?.(pageNum, total)
  }

  return dataUrls
}
```

Replace the existing `addPage` function with:

```typescript
const addPage = useCallback((f: File) => {
  setFileTypeError(null)

  if (f.type === 'application/pdf') {
    // Render all PDF pages and add each as a data URL
    pdfToImages(f).then((urls) => {
      if (urls.length === 0) {
        setFileTypeError(`"${f.name}" no contiene páginas renderizables.`)
        return
      }
      setPages((prev) => {
        if (prev.length === 0) setFile(f)
        return [...prev, ...urls]
      })
    }).catch(() => {
      setFileTypeError(`No se pudo leer "${f.name}" como PDF.`)
    })
    return
  }

  if (!f.type.startsWith('image/')) {
    setFileTypeError(`"${f.name}" no es una imagen ni un PDF.`)
    return
  }

  readFileAsDataUrl(f).then((url) => {
    setPages((prev) => {
      if (prev.length === 0) setFile(f)
      return [...prev, url]
    })
  })
}, [])
```
